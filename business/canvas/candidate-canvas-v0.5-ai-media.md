# 商业画布v0.5：发起人的AI自媒体与变现

2026-09-15。用户确认的是主线，不是具体用户、产品或收入；替代v0.4为当前工作画布。

| 要素 | 已确认/已有 | 假设与缺口 |
|---|---|---|
| 主体与主题 | 首先服务发起人自己的AI内容生意；研究AI如何变现 | 不提前跳到为其他行业做增长 |
| 受众/付款者 | 尚未选定 | 按实际任务细分；读者、广告主、企业付款者分开 |
| 问题 | 需要快速建立AI自媒体市场认知与切入判断 | 市场客户的问题频率、损失、替代方案、预算待研究 |
| 价值 | 用真实内容/案例帮助目标人群理解或完成具体AI相关任务，是候选价值 | 需由匹配用户反馈与使用/支付验证 |
| 内容与渠道 | 用户选择内容吸引目标用户；抖音优先调查，其他渠道补证 | 不默认所有平台同时做，不默认资讯/教程一定有付费需求 |
| 产品与转化 | 研究内容与产品承接；不先卖确定产品 | 广告、课/训练、模板/订阅、咨询/实施等均待比较 |
| 私域与关系 | 用户明确希望沉淀和形成复购 | 自愿加入理由、首次价值、交付、后续任务与留存机制待证 |
| 收入与复购 | 未定价、未取得本业务支付与复购 | 不以入群数、作者自述、销售页或订阅按钮代替结果 |
| 能力和资源 | 发起人AI项目与内容/销售/运营经验已有记录；研究方法与工具可复用 | 当前熟练程度、案例可公开范围、持续更新成本需核对 |
| 成本 | 保持小范围人工+AI实验，不擅自采购/付费 | 完整工时、工具费、交付与维护成本未知 |
| 下一验证 | 真实AI账号经营对照与成组内容阅读，再提切口及小实验 | 不继承跨行业发现池为AI样本；不先要求客户后台 |

研究方法与当前入口：`docs/ai-media-mainline-2026-09-15.md`、`research/ai-media-monetization-2026-09-15/report.md`。
