# 当前能力—客户任务匹配表 v0.1

更新日期：2026-09-12
用途：不复刻历史项目，从当前真实能力出发，选择一个最小可交付结果。

## 填写原则

- 写“现在能稳定完成什么”，不写“理论上AI可以什么”；
- 区分本人能独立完成、需要AI协助、需要额外工具/开发；
- 每项能力都要对应客户任务和验收结果；
- 不把历史项目的设计目标当作当前可交付能力；
- 先选1个1—3天可以做出样例的结果。

## 当前候选客户任务

### 专业人士/老师

- 把专业能力提炼成定位和内容主题；
- 建立内容—咨询—成交承接流程；
- 整理已有知识和咨询话术；
- 对内容和线索进行复盘。

### 本地生活商户

- 把门店卖点和活动转成内容；
- 建立内容—咨询—到店记录；
- 整理评论、咨询和客户反馈；
- 设计一周可执行的内容与跟进动作。

## 选择最小交付的判断标准

优先选择同时满足以下条件的条目：

1. 客户能看懂结果；
2. 结果不依赖复杂开发；
3. 1—3天可完成样例；
4. 不需要客户交出敏感资料；
5. 有明确的前后对照或验收标准；
6. 可以通过内容公开展示方法，但不公开客户隐私。

## 已确认的 AI 产品闭环证据：健康顾问

健康顾问 Agent 是当前最完整的个人项目能力证据。它已具备：

- 任务：把分散的健康数据转化为每周可执行的减脂调整；
- 输入：小米健康、Strava、手工/照片饮食记录；
- 处理：本地存储、趋势、恢复、训练负荷、饮食覆盖度和置信度；
- 输出：看板、训练/饮食/恢复建议；
- 反馈：用户执行、继续记录和后续同步；
- 工程交付：配置、定时同步、访问控制、测试、隐私边界和故障修复。

这证明发起人具备设计和实现“数据/资料 → 判断 → 行动 → 反馈”型 AI 辅助闭环的经验。它暂不证明外部客户付费或商业结果。
