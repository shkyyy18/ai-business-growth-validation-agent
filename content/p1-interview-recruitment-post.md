# P1 访谈招募内容草案

日期：2026-09-12
状态：待人工确认后发布；用途是招募访谈，不是销售产品。

## 目标

找到正在做专业服务、发布内容并接收咨询的老师或专业人士，邀请 20—30 分钟访谈。

## 文案

做老师、顾问或专业服务的人，你有没有遇到过这种情况：内容也在发，偶尔也有人咨询，但很难说清楚客户是从哪条内容来的、为什么没有继续、到底卡在回复、筛选、预约还是产品本身？

我最近在研究这个很具体的问题，只找 3 位正在做内容并接咨询的人聊一次最近的真实经历。不是卖 AI 课程，也不先推工具；只想把一次“有人来咨询，但最后没有预约/成交”的过程还原出来。

如果你愿意参与，可以私信我“访谈”，并告诉我：你提供什么服务、主要通过什么渠道获客、最近最容易卡在哪一步。我会安排一次 20—30 分钟线上交流，不需要提供客户姓名、联系方式、账户或其他敏感资料。

## 发布后记录

只统计：符合目标身份的人数、具体问题私信数、同意访谈人数、完成访谈人数、授权资料人数。播放量和点赞量不作为本轮成功标准。

## 公开前检查

- [ ] 没有承诺涨粉、成交或收入结果
- [ ] 说明这次是问题访谈，不是免费完整诊断
- [ ] 明确不收集客户隐私和敏感资料
- [ ] 设定最多 3 位首轮访谈名额
- [ ] 私信后用 `experiments/p1-interview-kit.md` 逐一记录
