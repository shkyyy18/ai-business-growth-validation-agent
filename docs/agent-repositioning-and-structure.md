# Agent 重新定位与总体结构

日期：2026-09-12
状态：讨论稿

## 一、Agent 不应再叫“AI 新媒体项目 Agent”

原名称把“新媒体”误当成了业务主体，导致框架天然从内容、直播和渠道开始，忽略了更上层的商业问题：客户是谁、问题是什么、如何创造价值、如何收费、如何交付和复制。

新的 Agent 应该服务于完整的“AI 业务变现”过程，新媒体只是其中一种获客和验证手段。

## 二、推荐名称

### 推荐正式名称：AI 商业增长验证 Agent

英文可暂定：`AI Business Growth Validation Agent`

推荐理由：

1. **AI**：说明 AI 是核心增强能力和研究对象；
2. **商业**：范围高于新媒体，包含客户、价值、产品、收费和交付；
3. **增长**：承接项目发起人在销售、流量、内容、运营和团队方面的既有能力；
4. **验证**：强调不凭想象选客户、产品或 Agent，而是通过假设、实验、交付和付费证据逐步收敛。

“验证”很重要，因为当前不是一个已经确定产品的执行 Agent，而是一个帮助发现并验证 AI 变现机会的 Agent。

## 三、其他候选名称

| 名称 | 优点 | 局限 |
|---|---|---|
| AI 商业增长验证 Agent | 商业范围、既有优势和当前阶段都能表达 | 名称稍长，但最准确 |
| AI 业务变现 Agent | 直接表达赚钱目标 | “变现”容易让人误解成流量变现或营销套路 |
| AI 经营增长 Agent | 更偏长期经营和交付 | 对“验证未知机会”的强调不足 |
| AI 商业化 Agent | 简洁，适合未来产品化 | 范围太宽，无法体现内容、获客和增长优势 |
| AI 增长运营 Agent | 承接过往经历 | 容易退回“运营工具”定位，缺少商业发现层 |

当前建议使用正式名称“AI 商业增长验证 Agent”，项目内部简称“商业增长 Agent”。

## 四、Agent 的核心任务

它不是单纯帮人写内容，也不是单纯帮人用 AI，而是：

> 帮助一个具备业务能力的人或小团队，发现值得解决的商业问题，设计 AI 增强型解决方案，验证客户价值和付费可能，再将经过验证的流程产品化和自动化。

对本项目而言，Agent 同时服务两个对象：

1. **项目发起人本人**：寻找自己的 AI 变现方向；
2. **未来客户**：帮助其解决具体业务问题。

第一阶段先服务项目发起人本人，把 Agent 当作商业机会发现和验证系统；后续才把其中稳定的流程转化为对外服务或产品。

## 五、总体结构：四层，而不是“新媒体八模块”

### 第一层：商业问题层（Why）

回答：为什么做、为谁创造什么价值。

- 能力资产与资源约束；
- 客户细分与场景；
- 问题、损失和紧迫性；
- 价值主张；
- 竞争和替代方案；
- 个人长期目标。

### 第二层：业务闭环层（What）

回答：具体提供什么、如何收费和交付。

```text
客户
→ 问题
→ 解决方案
→ 可见结果
→ 交付方式
→ 价格/付费
→ 复购/转介绍
```

- 商业画布；
- 产品形态；
- 成交理由；
- 单位经济；
- 交付容量；
- 结果证据。

### 第三层：增长与验证层（How）

回答：如何找到客户、验证需求并持续获得反馈。

- 新媒体内容；
- 私域和社群；
- 销售与访谈；
- 合作渠道；
- 线下关系和存量人脉；
- 实验设计；
- 线索记录和转化。

新媒体位于这一层，是渠道之一，不是整个 Agent 的上层框架。

### 第四层：AI 增强与复制层

回答：哪些环节可以用 AI 提高效率，哪些可以产品化。

- AI 辅助研究；
- 内容和方案生成；
- 客户问题整理；
- 工作流设计；
- SOP 固化；
- Skill；
- Agent；
- 软件化交付。

只有前面三层有真实证据，第四层才进入开发。

## 六、Agent 的核心循环

```text
能力与目标
→ 商业假设
→ 客户问题
→ 价值方案
→ 获客与沟通
→ 人工+AI交付
→ 结果与付费证据
→ 复盘
→ 收窄客户、问题和产品
→ 流程固化与自动化
```

这是一个循环，不是一次性项目计划。

## 七、新媒体在 Agent 中的位置

新媒体可以承担五个角色：

1. 展示能力和案例；
2. 获取潜在客户；
3. 测试不同问题是否引发真实反应；
4. 教育市场并降低沟通成本；
5. 承接咨询、诊断和成交。

但如果目标客户已经来自已有关系、人脉、合作伙伴或线下资源，就不必强行先做新媒体。渠道应由客户获取成本、信任要求和验证效率决定。

## 八、Agent 第一阶段不做什么

- 不先做内容生成器；
- 不先做自动发布系统；
- 不先做全自动销售机器人；
- 不先选定某个 AI 工具作为产品；
- 不把新媒体当成唯一获客方式；
- 不把“学会 AI”当成客户价值；
- 不在商业假设尚未验证前开发复杂 Agent。

## 九、第一阶段最小输出

1. 项目发起人的能力资产图；
2. 三到五组 AI 变现商业假设；
3. 每组假设的商业画布；
4. 客户访谈与问题证据；
5. 一个最小人工+AI交付实验；
6. 结果、付费和交付成本记录；
7. 下一轮收窄或停止决策。
