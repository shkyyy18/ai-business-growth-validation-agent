# AI商业顾问 MVP 实施待办与验收门 v0.1

更新日期：2026-09-13
状态：方案设计，等待用户确认后实施

## 1. 实施目标

先做一个服务项目发起人本人的单用户、单项目验证工作台，不做对外 SaaS，不做自动销售，不做自动发布。

第一轮必须跑通：

```text
读取状态 → 导入资料 → 能力卡 → 商业画布 → 假设排序
→ 访谈/实验卡 → 人工+AI小交付 → 证据记录 → 复盘决策
```

## 2. 开发范围决策

### 纳入 MVP

- 本地项目目录；
- Markdown/JSON 文件读写；
- 一个模型接口；
- 人工确认；
- 现有模板继续作为正式记录格式；
- 个人 IP 课程案例作为第一轮验收样本。

### 不纳入 MVP

- 多用户和权限；
- 数据库和向量数据库；
- 多 Agent；
- 自动发布、自动私信、自动直播回复；
- CRM；
- 浏览器自动化；
- SaaS 部署；
- 完整市场爬虫；
- 自动定价和自动商业决策。

## 3. 分阶段待办

### S0：确认方案

**产出**：技术与业务边界确认。

**必须确认**：

1. 第一版是否服务你本人；
2. 是否继续使用 Markdown/Git；
3. 是否接受单模型、单项目、人工确认；
4. 是否暂不接入 Dify、n8n、CRM 和浏览器自动化；
5. 第一轮是否使用个人 IP 课程案例验收。

### S1：文件工作流原型

**目标**：不追求复杂界面，先把业务流程跑通。

**任务**：

- 读取 STATE 和相关文件；
- 创建能力卡；
- 创建/更新商业画布；
- 创建假设卡；
- 创建访谈卡和实验卡；
- 生成复盘模板；
- 所有输出写回指定 Markdown/JSON 文件。

**验收**：使用同一份个人 IP 课程资料，能够完成一轮 N0—N10，不丢失来源，不把假设写成事实。

### S2：最小 Python 层

**目标**：减少重复复制粘贴，让字段和文件操作稳定。

**任务**：

- 定义数据模型；
- 校验必填字段；
- 读取和写入 Markdown/JSON；
- 提供最小 CLI 命令；
- 增加模型调用适配器；
- 记录调用时间、模型和人工修改时间。

**候选组件**：Pydantic/Pydantic AI；资料导入有实际需求时再加入 MarkItDown。

**验收**：缺少客户、证据或成功标准时，系统提示补充，不能静默生成完整结论。

### S3：真实小交付

**目标**：验证客户价值，不验证技术炫技。

**候选任务**：

> 使用客户已有内容、咨询记录和产品资料，完成一次内容—咨询断点诊断，或内容研究与选题交付。

**必须记录**：

- 输入资料和授权；
- AI 初稿耗时；
- 人工修改耗时；
- 客户修改次数；
- 客户是否采用；
- 是否进入执行；
- 客户是否愿意继续或付费。

**验收**：至少完成一次真实人工 + AI 交付并取得客户反馈。

### S4：按瓶颈接入组件

只有出现明确瓶颈才接入：

| 瓶颈 | 候选项目 |
|---|---|
| 资料转换重复 | `microsoft/markitdown` |
| 输出结构不稳定 | `pydantic/pydantic-ai` |
| 流程需要暂停、恢复和分支 | `langchain-ai/langgraph` |
| 市场研究需要多来源引用 | `assafelovic/gpt-researcher` |
| 需要本地操作界面 | `streamlit/streamlit` |
| AI 调用多、需要成本追踪 | `langfuse/langfuse` |
| 提示词需要回归测试 | `promptfoo/promptfoo` |
| 需要多模型路由 | `BerriAI/litellm` |

## 4. 业务验收门

### 继续开发

满足多数条件：

- 同一任务至少重复出现；
- 输入资料边界较稳定；
- 输出可以被客户直接采用；
- 人工修改时间开始下降；
- 客户明确表示有帮助；
- 出现继续合作、预算或付费信号。

### 调整方向

- 问题真实，但交付物不被采用；
- 客户需要的是代运营而不是诊断；
- 结果周期太长，无法观察；
- 输入资料严重不完整；
- 交付过度依赖发起人个人判断。

### 停止或暂停

- 客户没有实际问题事件；
- 客户不愿提供资料或执行；
- 交付结果无法验收；
- 反复表达兴趣但没有行动；
- 交付成本明显高于可能价值；
- 任务依赖平台高风险自动化。

## 5. 代码开始前的明确边界

用户确认前只做调研、文档和方案设计。确认后也应从 S1 或 S2 的一个最小切片开始，不一次性开发 N0—N11 全部功能。
