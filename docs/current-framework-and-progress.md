# 当前整体框架与进度总览

更新日期：2026-09-12
状态：当前工作地图，不是最终商业方案。

## 一、Agent 的总定位

项目正式名称：**AI商业顾问**。

它当前首先服务项目发起人本人，帮助完成：

```text
盘点能力与目标
→ 找到真实商业问题
→ 形成商业假设
→ 设计最小可交付结果
→ 用人工 + AI 完成验证
→ 获取执行、结果和付费证据
→ 收窄客户、任务和产品
→ 固化为服务、工作流、Skill、Agent 或软件
```

它不是“新媒体内容 Agent”，也不是先开发一个 AI 工具再找客户。

## 二、三个概念的关系

### 商业闭环：要解决的根本问题

```text
客户
→ 真实问题
→ 解决方案
→ 可见结果
→ 交付
→ 收费
→ 复购/转介绍
```

### 新媒体：获客、信任和市场验证渠道

新媒体可以用来展示能力、获取线索、测试问题、教育市场和承接直播/咨询，但它不是完整商业模式。

### AI：提高研究、交付、复盘和复制效率的增强能力

AI 是否使用、使用到什么深度，要由客户问题和交付结果决定。AI 本身不是客户价值。

## 三、四层结构

### 第一层：商业问题层（Why）

回答：为什么做、为谁创造什么价值。

包括个人目标、能力资产、资源约束、客户细分、具体问题、损失、紧迫性、价值主张和替代方案。

### 第二层：业务闭环层（What）

回答：具体提供什么、如何收费和交付。

包括客户任务、解决方案、结果、产品形态、成交理由、价格、交付容量、复购和结果证据。

### 第三层：增长与验证层（How）

回答：如何找到客户、验证需求并取得反馈。

包括新媒体内容、直播、私域、少量主动沟通、转介绍、合作渠道、客户试用、线索记录和实验复盘。

### 第四层：AI 增强与复制层

回答：哪些环节可以用 AI 提效并逐步复制。

包括资料研究、内容和方案生成、客户问题整理、工作流、SOP、Skill、Agent 和软件化。只有前面三层形成证据，才进入大规模自动化。

## 四、当前所处阶段

当前是：**阶段 1——从第一性原理重建能力与商业假设，进入历史经验提取。**

当前主线不是立刻卖某个课程，而是：

```text
你的真实能力与目标
→ 你的个人 IP 课程主案例
→ 提取可迁移的方法和人工判断
→ 与古筝/英语/钢琴/产康/财税项目交叉验证
→ 找到一个真实客户任务
→ 人工 + AI 完成一次小交付
→ 再判断是否值得收费、服务化或 Agent 化
```

## 七、已经计划但尚未完成的工作

### 第一阶段：完成主案例提取

1. 你按记忆说出个人 IP 课从开始到结束的大致模块；
2. 将每个模块拆成事实、方法、交付物、结果和 AI 任务；
3. 标记哪些方法在古筝、英语、钢琴、产康、财税项目中重复出现；
4. 区分可迁移能力、行业特定经验和必须依赖你的现场判断。

### 第二阶段：选择一个真实窄任务

从提取后的任务中选择一个：

- 高频发生；
- 输入资料相对稳定；
- 输出可以被客户直接采用；
- 结果可以在 7—14 天内观察；
- 不需要一开始承担整套代运营责任。

再用人工 + AI 完成一次完整交付。

### 第三阶段：熟人客户试用

当前计划是：

```text
选 1—3 位熟悉客户
→ 明确资料授权和试用边界
→ 完成一次真实任务
→ 观察采用、执行、结果和继续使用意愿
→ 讨论付费或继续合作
```

这一步才用来验证客户价值和商业可能，历史案例本身不能替代外部验证。

### 第四阶段：决定产品形态

只有出现重复任务、稳定交付和付费意愿后，才选择：

- 一次性诊断；
- 短周期陪跑；
- 人工 + AI 结果型服务；
- 课程或工作坊；
- 模板/Skill；
- Agent 或软件。

顺序不是预先决定的。

### 第五阶段：建立获客和内容系统

当客户任务和价值主张清楚后，再使用新媒体做：

- 问题教育；
- 能力展示；
- 客户案例；
- 需求测试；
- 直播/咨询承接。

内容优先独立成立；直播负责更深的信任、答疑和成交。不是每条内容都强行导流直播。

## 八、当前明确暂不做的事

- 不重新销售或完善旧的个人 IP 课程；
- 不凭历史案例直接确定未来商业方向；
- 不先开发完整 Agent 或软件；
- 不把“AI”单独包装成客户价值；
- 不把“新媒体”当成商业模式；
- 不同时推进多个客户群和多个产品；
- 不先安排大规模内容发布；
- 不把播放量、AI 生成字数或工具数量当成商业证据；
- 不在没有真实素材时声称已经完成视频剪辑；
- 不把健康顾问个人项目直接复制成对外产品。
