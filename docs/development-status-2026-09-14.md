# 开发说明

## 当前实现

2026-09-14 完成 S1 文件工作流的第一个可运行切片：

- 状态读取；
- 资料导入及来源指纹记录；
- 待人工确认能力卡；
- 商业画布和假设卡模板生成；
- JSON 记录校验；
- 标准库 smoke tests。

## 尚未实现

- 模型 API 适配器；
- Markdown 结构化解析；
- 自动更新正式业务记录；
- 多项目/多用户；
- 自动发布、私信、直播回复或销售决策。

## 原则

先让文件工作流在个人 IP 课程样本上跑通，再根据真实重复任务决定是否加入 Pydantic、MarkItDown 或 LangGraph。任何生成文件都先进入 `workspace/outputs/`，人工确认后再写入 `business/` 正式记录。


## 晚间：真实部分输入的全流程检查

新增两个可运行入口：`run-case`（来源指纹核验、真实账号/作品卡、N0—N11交接）和 `live-metrics`（调用方明确口径后的离线计算）。当前不是模型编排器，不自动生成访谈回答、商业判断、课程/话术或成交结果。

真实来源实验取得同一作者两条离散作品的ID/有名称的互动字段；原视频查看0，可靠全文0，连续列表和变现记录未得。执行产物见 `experiments/business-advisor-e2e-001/output/`。商业画布v0.3已与M1研究试用对齐，仍为候选。

测试通过仅验收所测代码行为。Windows子进程中文解码故障已复现并修复；当前代码测试计数/退出码见该实验test-run.json。M5用合成算术输入，不是客户直播实测。仍缺真实客户授权、问题/基线、采用/执行、结果及成本。
