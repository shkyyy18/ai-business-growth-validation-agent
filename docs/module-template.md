# 新媒体模块工作模板

每个模块都使用同一套记录方式。先允许内容为空或只有初步假设，随着实践逐步补充。

## 模块名称

当前状态：`未开始 / 已设计 / 已手工验证 / 已稳定运行 / 可自动化 / 可复制交付`

## 1. 模块目标

这一模块要为整个业务带来什么结果？

## 2. 当前事实

只记录已经知道、做过或有证据支持的内容。

## 3. 当前假设

记录暂时相信但尚未验证的判断，并为每条假设设置验证方式。

## 4. 输入

这个模块需要哪些资料、数据、客户信息或上游结果？

## 5. 输出

这个模块要产出什么具体文件、动作、决定或结果？

## 6. 当前流程

```text
步骤 1 → 步骤 2 → 步骤 3
```

## 7. 衡量指标

区分过程指标、行为指标和业务结果指标，不用单一指标代表模块有效。

## 8. 问题与待验证事项

- 当前最大的不确定性是什么？
- 哪个问题最影响下一步？
- 用什么最小实验可以验证？

## 9. AI、Agent 和 Skill 候选

记录可由 AI 辅助的步骤，但只有在人工流程稳定、重复性明确后才进入开发或选型。

| 步骤 | 频率 | 耗时 | 规则清晰度 | 风险 | 候选方式 |
|---|---:|---:|---:|---:|---|
|  |  |  |  |  | 人工 / AI 辅助 / Skill / Agent / 暂不处理 |
