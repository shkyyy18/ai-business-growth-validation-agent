# 单条内容：先逻辑，再顺序，再逐句映射

这是通用公开方法，不附带实际原片、个人原稿或客户反馈。配套[空白审阅表](templates/single-content-storyboard-review.md)。

1. **G0 输入与范围**：确认本轮目标、参考材料权利、原稿版本与允许操作。原稿另存不覆盖；调序、改字、制作与发布分别授权。
2. **G1 参考证据**：先说明原片解决什么问题、如何举证、如何结尾；时间码、实际观看范围、声音核验与缺口分开记录。字幕或摘要不能冒充视听分析。
3. **G2 原稿顺序**：逐段说明任务、相邻关系与移动理由。纯调序保留原字；改字提案单列。相邻不是因果，节拍不是独立物理镜头。
4. **G3 逐拍映射**：区分直接对应、换题材、仅借形式和新增。标明参考范围、自有证据、素材需求及不确定性；不得复制别人的身份、业绩或个人经历。
5. **G4 制作与验收**：只在确认的范围内制作；同模板节拍可合并，已确认资产直接复用。新版另存，检查时序、声音、图像与缺失项，再由用户审阅。

已有范围与原稿已确认时，不强制重跑所有步骤。技术检查、人工听审、审美认可、公开使用权及商业反馈分别记录；空白意见不算通过。所有实际作品与个人记录仅放在本地忽略目录，不将真实资料换名冒充合成示例。
