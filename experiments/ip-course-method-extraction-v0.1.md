# 个人 IP 课程：方法论与 AI 任务提取 v0.1

更新日期：2026-09-14
状态：主案例拆解稿；不代表重新销售、重做或重新上线这门历史课程。

## 一、案例用途

这份案例用来提取发起人已经做过、讲过和交付过的工作方法。它要回答的是：

> 发起人过去到底用什么判断，帮助别人把专业能力变成个人 IP 和业务结果？其中哪些工作可以由 AI 辅助，哪些工作必须保留人工判断？

它不用于：

- 重新设计历史课程；
- 确定现在的课程价格或销售计划；
- 证明历史客户今天仍愿意购买；
- 直接把“个人 IP 课程”确定为未来商业产品。

## 二、为什么把个人 IP 课作为主案例

古筝、英语、钢琴、产康和财税等项目，是方法在不同专业领域中的应用案例。个人 IP 课程则更接近发起人自己的方法论总集，能够观察：

- 发起人如何定义个人 IP 的业务目标；
- 如何把客户的专业能力组织成定位、内容、直播、产品和交付；
- 哪些判断可以反复迁移到不同专业领域；
- 哪些内容只是当时的行业经验，不能直接抽象为通用方法；
- 哪些环节可能适合 AI 辅助，形成可重复的工作流。

## 三、目前已确认的事实

以下内容来自发起人的自述，属于已确认背景：

- 发起人自己做过个人 IP；
- 曾通过教授个人 IP 方法销售课程；
- 曾为客户提供个人 IP 全案孵化；
- 合作对象包括古筝、英语、钢琴、产康、财税等专业老师或专业服务者；
- 历史交付涉及内容、直播、课程产品、私域和交付等多个业务环节；
- 发起人现在希望从这些历史经验中提取 AI 可以帮助别人完成的任务，而不是直接复刻历史项目。

## 五、拆解方法

每个课程模块都按以下链路提取，不把“讲过一个概念”直接等同于“形成了可交付能力”：


## 七、初步能力假设

这些是待课程材料验证的工作假设：

1. 发起人的核心能力可能不是单点内容生产，而是把专业能力组织成一条“定位—内容—直播—产品—交付”的业务链路。
2. 发起人的可迁移能力可能是从复杂经历和业务资料中提取主线，并把主线转换为客户能够执行的内容与动作。
3. AI 的首要价值可能是降低研究、整理、改写、记录和复盘成本，而不是替代发起人的业务判断。
4. 真正可能形成商业价值的交付，不一定是一个完整的“课程增长 Agent”，也可能是某个高频窄任务，或人工 + AI 的诊断/陪跑服务。
5. 这些假设必须经过课程方法提取、历史项目对照和至少一次真实任务演练后，才可以进入商业画布。

### 10.2 对前次整理的修正与补充

1. **行业研究是客户诊断的前置准备。** 用户明确“一般在客户沟通前做约两周行业调研”；不能继续把“先完整诊断客户，再开始研究行业”当作固定顺序。是否针对每位客户重做、已有行业资料是否复用、两周实际投入工时尚未知；不将两周写成当前服务周期或价格依据。
2. **诊断不是看到数据差就判定内容不好。** 用户会区分缺少系统方法论、内容制作与平台表现不适配、内容本身的问题，并判断客户所处行业水平。这些是诊断候选解释，不预设互斥，也不在缺少样本时确认因果。
3. **对标账号关注变现，信息来源已有说明。** 用户会查看抖音商城中的小店销售记录，同时关注爆款结构、行业动态和热点。具体可见字段、时间范围、数据取得方式、账号与商品关系尚未提供；后续只记录实际看到的字段，不把“研究变现”自动升级为已核验利润或完整成交数据。
4. **内容筛选有两类入口。** 一类是按账号与点赞表现筛选，再拆解高赞内容；另一类是数据不好但被用户判断为内容很好的样本，再研究如何调整表达和制作。不能把低赞内容全部剔除，也不能把高赞自动视为可迁移或有变现效果。
5. **产品决策属于客户。** 发起人根据客户实际情况寻找卖得好的参考产品并提供建议，由客户作为行业专家决断；不替客户自动决定产品、课程承诺或交付范围。
6. **直播包含测试、数据分析和复盘。** 用户关注停留、流量流入快慢、ROI、千次观看成交、进入率、转化率；尚未说明具体口径、目标阈值、比较方式及测试后的动作。
