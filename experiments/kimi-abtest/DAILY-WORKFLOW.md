# 每日实测交接与续接

## 每次真实任务的顺序
1. 用户提供当天任务、必要新资料和允许使用范围；不读私密访谈，除非另行明确授权且符合原始同意范围。
2. 在Codex开始修改业务产出前复制任务输入；固定目标、允许写入范围、验收项和错误判据。
3. A执行真实任务，另存未修订原始答案。B使用同一份任务前资料与Codex计划，不使用A完成后的STATE/画布等。
4. 记录B计划生成耗时/调用，执行耗时/调用，双方复核、返工及人工干预。失败保留日志，环境/权限故障不混成推理错误，但计入工作流开销。
5. 逐项比较事实、关键判断、遗漏和边界，而非逐字相同。用户分别评价：可直接采用/小改可用/需重做，并说明理由。
6. 经用户确认再决定是否采用成果；本实验默认只写隔离产出。不得将两份矛盾产出自动合并进业务记录。

## 后续任务池（按真实进展选，不提前假定用户答案）
- 低难度：恢复主线状态、提炼已确认决策、找唯一下一步。
- 中难度：整理用户亲自完成的一项AI任务，区分本人操作/AI操作/缺失证据，形成能力卡片建议。
- 中高难度：将能力样例映射到候选客户任务，指出不匹配与待核验边界，设计最小交付验证而非直接包装产品。
- 高难度：在新增事实与旧画布冲突时提出状态/假设修订建议，保留来源与不可下的结论。
- 恢复测试：双方在同一检查点、同等上下文预算下续跑；人为中断单列，不充当真实故障率。

未发生的客户访谈、付款或交付只能作为明确标注的模拟材料；不能写成真实业务事实。

## 每日记录模板
- 日期/任务/输入快照/难度：
- A环境与模型标识；B环境与模型标识（无法验证的后端写未知）：
- 首轮分数与逐项证据；硬失败；用户验收：
- A生成/复核/修订成本：
- B计划/执行/复核/修订成本：
- 各方首个可用结果耗时、失败尝试、用户干预分钟：
- 账单依据、缺失数据和偏差：
- 下一次最需要补测的真实任务：

## 1000元情景的最后计算
用户报价假设：Kimi每月699元，Codex留301元。不预分配“计划占比/执行占比”，先量出日均计划与复核开销，再判断301元是否覆盖预计月任务量。

Codex独立月成本 = 实际独立执行 + 复核 + 返工调用费。
组合月成本 = 699 + 实际Codex计划/复核/返工调用费 + Kimi超额费用（若有）。
已付套餐剩余试用期成本另列，不用接近零的边际支出证明长期续费划算。只有满足同等验收标准且无硬失败的任务计入有效产出；人工时间单列，不擅自给用户工时定价。
