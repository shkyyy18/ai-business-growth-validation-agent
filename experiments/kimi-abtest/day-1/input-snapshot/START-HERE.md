# 启动说明

## 新 CLI 会话

```powershell
cd D:\AIWork\projects\ai-new-media-agent
```

然后输入：

```text
商业顾问
```

## 启动时必须读取

- `README.md`
- `START-HERE.md`
- `AGENTS.md`
- `docs/project-brief.md`
- `docs/decision-log.md`
- `docs/agent-repositioning-and-structure.md`
- `docs/ai-monetization-and-business-canvas.md`
- `agent/AGENT.md`
- `business/` 中当前有效的画布和实验记录

启动后汇报：

1. Agent 当前使命和服务对象；
2. 当前阶段；
3. 已确认的决策；
4. 当前商业假设和证据等级；
5. 画布和实验状态；
6. 上次未完成的下一步。

然后直接继续当前最合理的一步，不重新讨论已经确认的方向。

## 指定工作

```text
商业顾问，继续做个人商业画布。
商业顾问，比较三组 AI 变现假设。
商业顾问，整理客户访谈记录。
商业顾问，复盘这次交付实验。
```

## 续接入口

启动时先读 `business/STATE.md` 和 `business/founder-profile.md`，再读其关联画布。每次收尾更新 STATE.md。历史文档中的下一步若与当前状态冲突，以当前状态和最新用户决策为准。

## 适用范围

在 Codex 中打开 `D:\AIWork` 或本项目目录，再输入“商业顾问”。CLI 可先切换到上述目录再启动 Codex。此为项目规则入口，不是任意目录都可识别的全局命令。也兼容旧口令“新媒体”。
