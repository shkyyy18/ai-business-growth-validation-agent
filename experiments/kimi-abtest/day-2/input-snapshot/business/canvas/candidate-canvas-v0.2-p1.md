更新日期：2026-09-12
状态：第一轮验证画布，不是最终定位。

| 画布要素 | 当前假设 | 证据状态 |
|---|---|---|
| 客户细分 | 有专业能力、已有服务产品、持续发布内容但咨询/预约不稳定的个人或小机构 | 来自历史合作圈和经验，未访谈验证 |
| 客户任务 | 找出内容到有效咨询/预约的关键断点，并跑 7 天改进实验 | 尚无外部交付 |

| 客户结果 | 一个明确优先断点、可执行动作、可追踪指标和一次复盘 | 可由现有能力做样例，结果未验证 |
| 价值主张 | 用客户真实资料做人工 + AI 诊断，缩短从模糊感觉到下一步行动的时间 | 工作假设 |
| 渠道 | 内容公开展示问题分析和方法；老客户/同行转介绍；少量定向访谈 | 符合用户偏好，转化未验证 |
| 客户关系 | 先访谈，再一次性诊断，结果成立后再提供短周期陪跑/实施 | 未验证 |
| 收入 | 诊断试单价格假设 999—1999 元；后续实施另行报价 | 仅实验锚点 |
| 关键资源 | 个人 IP 与新媒体经验、销售/交付经验、AI 结构化和工作流能力、项目案例 | 能力有个人项目证据，外部商业证据不足 |
| 关键活动 | 访谈、资料诊断、人工复核、7 天实验设计、结果复盘、内容公开表达 | 可执行，尚未跑通 |
| 关键合作 | 客户提供脱敏资料并执行记录；必要时与内容/投放/技术人员协作 | 依赖关系待验证 |
| 成本 | 访谈与诊断时间、内容制作、工具/API、客户沟通和交付复盘 | 具体成本未测 |
| 风险 | 客户实际需要代运营或投放；无基线/不执行；问题根源是产品或流量；诊断结果难归因 | 已识别，须在试单中记录 |

## Why / How / What 当前版本

### Why

帮助已经有真实业务的人，把持续发生的获客、咨询或销售卡点看清，并形成下一步可执行改进。

### How

用内容公开表达真实问题并获取线索；用少量访谈确认具体事件；用人工 + AI 整理资料、生成判断草稿和执行表；用客户执行后的行为数据决定是否继续、收费和标准化。

### What

第一件验证中的产品是“内容到有效咨询/预约诊断”，包含一次资料诊断和 7 天改进实验设计。课程、陪跑、全案孵化、软件和 Agent 都暂时是后续形态，不提前决定。

## 需要被客户验证的句子

> 我不是帮你泛泛做内容，也不是先教你一套 AI 工具；我先看你最近真实的内容和咨询，找出一个最值得先修的转化断点，再给你一周能执行和观察的改进方案。
