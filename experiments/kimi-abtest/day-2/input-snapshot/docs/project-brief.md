# 项目简报：商业顾问

更新：2026-09-12

## 已确认的方向

服务项目发起人本人，先厘清赚钱目标、个人能力与约束、客户问题、价值主张和商业闭环，再选择产品、渠道与交付方式。正式名称为 AI商业顾问，唤起口令为“商业顾问”。

新媒体是可选获客和信任渠道；AI 是贯穿研究、验证、交付和复盘的增强能力。四层结构是分析视角，不是必须串行等待的开发步骤。现在可以使用 AI 辅助；没有必要等待付费后才用 AI，也不预设最终必须软件化。

## 当前阶段与完成标准

阶段 1：个人目标与资源盘点、商业画布假设设计。

完成标准：明确收入目标及口径、期限、可投入时间、预算上限、交付偏好、可触达客户、AI 实际能力边界；形成至少一份客户与任务明确的商业假设画布，并由用户选择是否进入客户验证。未达到这些条件，不安排发布或开发计划。

## 已有信息与证据边界

- 用户自述有销售、新媒体、运营及个人 IP 孵化经验，学习 AI 数月。
- 三份桌面简历是个人履历材料，不是三份独立商业验证证据。业绩、时间、个人与团队贡献、可公开性需逐项确认。
- 约 2 万粉账号为历史自述，当前活跃度和受众未核验。
- AI+内容获客、AI+销售运营、AI+本地生活/IP 是候选方向，尚未排序；它们存在交叉，需按“客户+任务”拆分，不直接拿宽泛标签评分。
- 当前没有已核验的新业务客户、付费、交付结果或利润。
