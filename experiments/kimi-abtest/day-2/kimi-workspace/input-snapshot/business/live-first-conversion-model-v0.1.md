# 直播优先的内容与成交模型 v0.1

更新日期：2026-09-12
状态：根据发起人真实业务判断修正，待真实直播数据验证。

## 核心判断

对于 1999 元的专业人士个人 IP 课程，短视频内容主要承担“筛选人群、提出问题、建立初步认知、引导进入直播间”的任务。高信任产品的价值理解和购买决策主要在直播中完成。

因此，短视频不直接承担完整成交，也不把评论/私信咨询作为默认主路径。

## 业务闭环

```text
目标人群识别
→ 短视频提出具体问题并展示判断力
→ 用户进入直播间
→ 直播持续建立信任、答疑、演示方法和处理异议
→ 用户理解课程适用性与价值
→ 直播间成交/进入后续承接
→ 课程交付
→ 私域服务、作业、反馈和复购
→ 数据复盘反哺内容与直播
```

## 各环节的唯一任务

| 环节 | 主要任务 | 不应承担的任务 |
|---|---|---|
| 短视频内容 | 让目标专家意识到问题，并产生“这场直播我需要听”的理由 | 直接讲完整课程、直接完成高信任成交 |
| 直播 | 用连续表达、案例、答疑、演示和互动建立信任，完成价值解释与购买决策 | 只重复短视频，或只追求在线人数 |
| 课程产品 | 给直播中已经理解问题和方法的人一个明确、可执行的学习结果 | 用模糊的“打造个人IP”承诺覆盖所有人 |
| 私域交付 | 帮学员执行、答疑、交作业和获得反馈 | 代替前端内容和直播解决定位问题 |
| 数据复盘 | 看内容是否带来目标人群和直播行为，直播是否完成信任和成交 | 只看播放量或点赞量判断商业成功 |

## M1 的内容验收指标

M1 的第一业务指标应围绕直播，而不是咨询：

- 目标人群有效互动数；
- 直播预约/提醒/进房人数；
- 内容带来的直播间访问占比（如果平台可获得）；
- 直播间停留、评论和关键问题数量；
- 直播后课程成交或后续承接人数；
- 每条内容对应的直播主题和用户问题是否一致。

播放量、点赞量、评论数量只能作为辅助指标。没有直播场次和基线时，不承诺内容直接带来成交。

## M1 内容结构要求

每条内容必须先定义：

1. 它筛选哪类专业人士；
2. 它指出哪一个真实问题；
3. 它展示什么判断或方法；
4. 用户为什么要进入下一场直播；
5. 直播中将继续回答什么问题；
6. 内容和直播之间的承诺是否一致。

行动入口优先使用：

> 预告直播主题、直播时间和直播间将继续回答的问题。

评论可以用于收集问题和判断意向，但不默认把用户转入一对一咨询。

## 直播与 M1 的接口

M1 交付内容时，应同时输出：

- 对应直播主题；
- 直播中要继续回答的 3—5 个问题；
- 评论区可能出现的反对意见；
- 内容承诺和直播承诺的对应关系；
- 直播预约/进房的行动入口；
- 直播后课程价值解释需要补充的内容。

这为 M2 直播评论与转化辅助提供结构化输入。
