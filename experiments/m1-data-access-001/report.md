## 目标与边界

验证公开入口和候选服务能否支持发现账号、持续读取作品、核对原内容和表现数据。未安装项目、未登录账号、未发送 API 密钥或 Cookie、未启用付费套餐。没有原视频观看、客户交付或商业结果。

## 实际操作与证据

### 1. 一次公开演示 API 请求

- 文档：https://docs.tikhub.io/337619230e0
- GET：https://api.tikhub.io/api/v1/demo/douyin_search/app/general_search
- 实际请求元数据：`network-probes.json`，开始时间 2026-09-14T09:10:04.720822+00:00。
- HTTP 200、JSON code 200，内层 data 列表有19个原始条目；只确认响应与列表存在，不等于19个有效作品或账号。
- 文档明确固定“美食”关键词，无需参数、1小时缓存。无行业关键词测试，结果不纳入知识付费行业样本。
- 返回有 cursor / has_more 键，未保留值、未翻页，不能声称分页可用。未逐条核对作者ID、作品ID、原文、统计字段或时效。
- 文档称免费，但实际返回 message_zh 为“请求成功，本次请求将被计费。”未关联密钥且无账单，既不认定实际扣费，也不保证零费用。停止追加演示/API调用，先澄清费用。
- 返回还含24小时请求追溯缓存说明；它与文档的1小时演示数据缓存不是当然同一个概念，不能据此确认数据实时性。
- 完整响应未落盘，只保存元数据、字节数及SHA256；无可继续解析的原始条目。4.281秒只是该请求耗时，不代表整体研究效率。

- 原视频页 https://www.douyin.com/video/7455313258111716667 返回HTTP 200，但简单正文提取为空。只说明本次读取方式未取到正文，不说明视频不存在或所有访问方式都失败。
- 聚合页 https://www.douyin.com/shipin/7644393111137011758 返回可读标题、作者名称、日期、粉丝/获赞标签和推荐列表。页首为“进击的李同学（重庆小班9月）”的“一分钟学会如何用Deepseek生产出80分的脚本！”，标注2025-02-19 20:19，是历史材料。

- 可读的“AI文稿”出现在下方其他推荐作品区域，不能归给页首作者。主作品原文、原链接与稳定ID仍待核对；聚合URL中的数字不直接认定为作品ID。
- 本轮仅保存有限预览和证据片段，没有抓取完整账号列表、下载视频或批量收集推荐账号。推荐文稿仅作来源错配风险观察，不作深拆输入。
