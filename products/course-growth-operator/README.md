# 专业老师课程增长运营 Agent

版本：v0.1
状态：M1 内容研究与生产 MVP

## 它解决什么问题

专业老师有课程或服务，也知道需要做内容，但常见工作被拆散在多个地方：找对标、看内容、想选题、写脚本、拍摄、剪辑、引流直播。这个 Agent 先把这些工作组织成一条可执行的生产流程。

它不是“输入一句话生成文案”的工具，也不承诺爆款或成交额。第一版的验收是：客户能否用它更快地产出并发布至少一条符合自身业务的内容。

## 当前能力边界

### M1：内容研究与生产（当前可用范围）

- 对标账号和公开内容整理；
- 对标内容结构拆解；
- 受众问题、购买阶段和内容目的归类；
- 选题池；
- 内容 brief；
- 口播脚本、分镜和拍摄清单；
- 已有视频的转写、结构标注和剪辑方案；
- 字幕、封面、标题和行动入口建议；
- 发布后数据记录与下一轮复盘。

### 后续能力规划

- M2：直播评论回复、意向识别和 FAQ 调用；
- M3：热卖课程结构研究和课程产品设计；
- M4：私域 SOP、标准化话术和 QA；
- M5：内容、直播、产品和私域数据复盘。

后续模块只有在 M1 真实使用中出现稳定重复输入、明确人工判断点和持续需求后再加入。

## 使用原则

1. 先确认课程/服务、目标客户、平台和本轮业务目标。
2. 先从公开资料和客户提供资料中提取事实，再提出判断。
3. 对标内容只提取结构、问题表达和可验证的公开信号，不复制原文、画面或受限制内容。
4. 每次只为一个目标产出内容，例如引流直播、获得私信或测试一个课程主题。
5. AI 给出草稿和候选，客户确认专业准确性、表达风格、合规边界和最终发布版本。
6. 剪辑建议要落到时间轴、保留/删除片段、字幕重点和画面动作，不能只给泛泛建议。
7. 发布后记录业务指标，播放量只是背景信息，不能替代有效互动、咨询、进房或成交。

## 默认输出顺序

```text
业务与受众确认
→ 对标账号卡
→ 对标内容卡
→ 选题池
→ 单条内容 brief
→ 脚本与分镜
→ 剪辑方案
→ 发布记录
→ 数据复盘
```

## 人工审核边界

人工必须确认：专业事实、课程承诺、价格和优惠、版权/授权、未成年人或健康/财税等敏感表达、最终发布、直播中的即时承诺和成交决策。

Agent 不自行联系客户、不自动发布、不自动承诺结果、不把客户资料用于其他客户、不暴露内部商业顾问文件。
