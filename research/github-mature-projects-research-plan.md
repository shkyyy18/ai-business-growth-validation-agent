# GitHub 成熟项目借鉴研究计划

日期：2026-09-11
状态：`待检索`

## 研究目标

寻找可以支撑新媒体经营链路的成熟开源项目、Agent、Skill 和工作流，优先借鉴已有结构，再映射到本项目框架。当前不直接开发，也不因 Star 数量直接做商业判断。

## 检索范围

1. Agent Skills / SKILL.md 类可复用能力
2. 内容研究、选题、脚本和长短内容改写
3. 社交媒体发布、内容日历和跨平台管理
4. 评论、私信、线索和 CRM 承接
5. 营销自动化、工作流和数据复盘
6. 直播、销售、客户交付和知识库流程

## 项目评估字段

| 项目 | URL | Stars | 最近维护 | License | 核心模块 | 输入 | 输出 | 可复用部分 | 改造成本 | 风险 | 对应本项目模块 | 证据等级 | 初步结论 |
|---|---|---:|---|---|---|---|---|---|---|---|---|---|---|

## 评估原则

- Star：只作发现和初筛信号。
- 代码和文档：判断是否真的可运行、可理解、可改造。
- Issue、Release 和提交记录：判断维护和使用情况。
- License：确认是否允许当前用途。
- Demo 或真实案例：判断功能是否达到预期。
- 与项目流程的匹配度：判断是否能嵌入八模块，而不是只看功能数量。
- 隐私、平台规则、账号权限和自动化风险必须单独记录。

## 输出顺序

```text
候选项目清单
→ 单项目拆解
→ 横向能力矩阵
→ 映射到八模块
→ 人工确认
→ 决定借鉴/改造/暂不采用
```

## 暂不做

- 不直接复制开源项目代码。
- 不直接安装或运行未知项目。
- 不因为高 Star 就认定存在付费需求。
- 不在研究报告确认前开发本项目 Agent。
