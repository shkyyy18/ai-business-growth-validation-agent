# AI账号发现与对标研究

这是由当前会话驱动的浏览器研究工作流，不是独立后台爬虫。工具可用时自行导航、阅读、滚动、去重和保存，不逐页要求用户点击。Skill不能增加工具权限，安装和配置不等于端到端实测通过。

实测基线（2026-09-15）：一个真实账号的自主搜索、点击账号、打开主页、读取作品、返回和保存已通过；期间存在可恢复的点击失败。未证明批量无人值守稳定性或完整视频理解。方法见[浏览器执行与恢复](references/browser-execution.md)，验收边界见[验证记录](references/validation.md)。

## 接续与范围

在项目根目录工作，先读当地AGENTS.md、business/STATE.md最后续接节、关联研究任务及private中的本任务检查点。本Skill所在仓库即商业顾问项目；涉及对标适配时读当前画布和发起人档案，不读无关私有材料。无需复读全部历史日志或重装已存在服务。

遵循用户最新阶段：
1. 关注范围内AI相关性核验；
2. 少量证据完整的样例供用户校准；
3. 获准后补找外部相似账号，注明新增来源；
4. 比较对标适配性，不替用户锁定商业方向。
用户要求全流程自主执行时，不逐页请示；已有校准检查点仍保留，不因实现自动化跳过校准。仅讨论能否自动化不等于批准无界研究。

## 连接与能力检查

本轮以实际工具目录和调用结果为准，不能机械继承旧STATE中的“只有snapshot/需要重启”。只用当前实际暴露的工具操作浏览器。已有连接直接snapshot检查当前授权页面，不重复公开页验收。Welcome连接提示不等于已读目标页。

最小能力：snapshot读取、click点击；navigate打开已取得链接、navigate_back返回；press_key对列表滚动；type输入任务相关搜索；wait_for等待；tabs仅用于本任务打开的页。工具的实际名称和schema以本会话为准，不能调用猜测接口。

只有snapshot时，不在名单页循环读取后声称已访问主页。说明缺少交互工具并保存断点；配置已补齐但会话未加载时请求一次重新进入会话，而不是要求用户逐一点击账号。不通过exec、CDP或自建MCP客户端替代缺失/被拒绝的页面工具。不自动改安装、免确认token、访问策略或浏览器配置。

登录、验证码和扩展授权交用户本人；出现权限拒绝立即停下，不换工具绕过。限流/连续无新增或页面异常按下文保存退出，不无限重试。不读取Cookie、存储、私信、凭据或无关标签页。

## 自主浏览循环

1. **发现队列**：读取关注名单或用户指定公开种子，保存最小范围快照到工具允许的私有路径。不要把视频区的“没有更多”当名单到底。snapshot太长就写允许路径的文件后离线解析，见下方导入脚本。所有账号进入待核验队列，昵称不作排除条件。
2. **身份与导航**：指定账号优先使用关注列表自己的搜索框，保留所有相似昵称并核对精确目标；不能用全站搜索结果替代关注关系核验。快照取当前账号卡片ref或真实主页链接，自行点击/导航；核对确实到达对应主页。点击卡片可能仅筛选视频流，需再点击作者主页入口。ref失效则重新snapshot再定位，不反复使用旧ref。禁止从昵称猜主页地址。
3. **页面上下文**：记录本任务原列表URL及返回位置，优先同标签页导航。若站点新开页，仅选择可确认由此次任务创建的页；不得浏览或导出其他页内容。tabs列表如包含无关元数据，不保存不使用。不可确定新页归属就停下核对。结束时关闭仅本任务创建且不再需要的页，回到原任务页并用快照确认列表和筛选条件；返回页URL正确不等于弹层已经关闭。
4. **核验内容**：按[证据与分类](references/evidence-and-calibration.md)读取主页、普通作品、代表作品实际文字；平台AI章节摘要可作为降级证据，但须明确区别于作者原文、逐字稿和完整观看；只能支持暂定分类，不算已验证工具功能。多模态或正文不可访问时标明阅读边界。未读内容不可补写。
5. **逐账号落盘**：保存身份、来源、观察时间、已读证据、暂定分类和待核实项；原子更新检查点，随后返回队列处理下一个。昵称只能是临时标识，遇到同名不自动合并；优先用抖音号或真实主页路径去重。
6. **加载更多**：在关注名单容器上取得焦点再小步滚动，snapshot验证出现新账号；不要把右侧视频切换当名单滚动。每次保存首尾锚点、条数与新增稳定身份。若两次合理滚动/等待后无进展，记录“停滞，完整性未知”，不要宣称到底。
遇到ref失效、点击超时、遮挡或快照文件定位问题时，读取[浏览器执行与恢复](references/browser-execution.md)，按失败类型做有限恢复，不循环重装。

7. **交付校准**：首批选不同边界类型、证据足够的少量账号，给出实际判断和依据；其余继续保持待核实。用户纠正写入本任务校准记录，不把一句偏好泛化到所有行业。以最新STATE决定继续或等待校准。

## 补找和选择对标

只有范围允许时执行。根据已核验账号的受众任务、主题、工具/模型、内容形式在公开搜索及站内搜索找近邻；关键词只是发现手段。新账号也需主页和内容核验；搜索摘要不等于完整阅读，平台推荐不等于相关性。公开检索不带用户关注关系、私人档案或凭据。

分别比较：受众问题是否相近、内容形式是否可借鉴、普通内容是否有持续价值、产品承接证据、发起人能力/资源是否适配。用文字理由与证据，不伪造客观总分。粉丝量、名气、点赞不直接决定对标；专家/平台/企业和个人创作者分开。挂牌、自述、页面销量、真实支付及利润分开记录。方向尚未确定时给出不同用途的候选，不宣布唯一标杆。

外部账号不可穷尽：按新增主题、受众、产品结构的边际增量决定批次；默认先做小批而不是无限搜索。到校准点、预算边界、访问阻碍或信息重复时交付断点。

## 私有输出与验收

正式方法放项目研究目录；个人关注关系、原始材料、队列、候选表和校准记录默认private/douyin-following/。MCP文件根若不允许此路径，使用其明确允许且已确认Git忽略的服务目录，不修改限制；需要私有目录却不可用则停止保存，不落到公开目录。

每轮区分：已配置工具、已连接页面、已导入名单、已读主页、已读作品、暂定AI账号、已校准对标账号。这些数量不得混用。列表全量只在末尾证据、无加载缺口、身份去重及计数差异解释均成立时确认；昵称数量对齐不是充分证据。

结束更新STATE：本轮证据与局限、队列位置、下一主动作。报告不声称后台会继续运行。不给用户重复安装步骤；有可用工具时不把普通导航交还用户。

### 现有快照导入辅助

仅在已有隔离的普通关注账号列表快照时运行（不接收整页、作品卡片或搜索高亮拆词结果）`scripts/import_following_snapshot.py`：

```powershell
python -X utf8 skills/ai-account-discovery/scripts/import_following_snapshot.py --snapshot private/browser-playwright-mcp/following-list.yaml --output private/douyin-following/imported-queue.json
```

脚本仅离线提取名单与来源，不连接浏览器、不执行网页代码、不判断AI相关性、不用昵称合并身份；已有输出拒绝覆盖，避免破坏研究断点。实时研究记录另行维护。

## 公开资料补证与来源降级

当登录浏览器缺少交互工具时，可在用户已授权的公开研究范围内使用现有web搜索/打开工具，读取同名公开账号、作者自有网站、本人仓库及公开作品。此为公开资料研究，不是登录浏览器主页已读；不能访问被权限拒绝的同一受保护资源或用公开渠道反推用户私密资料。

单独记录access_mode：live_browser / public_page / indexed_platform_text / third_party。搜索结果若返回平台智能文稿可以按索引文字分析，必须标明缓存、非实时、机器文稿可能失真；只有摘要就只记摘要。直接打开空白或失败不能写成功。跨平台身份需作者互链或自述支持；仅同名视作暂定关联，不当作用户实际关注账号的稳定身份核验。

用户明确允许在离开期间继续对标及内容研究时，输出待校准建议并继续有限内容试拆，无需等待其返回；但不能把待校准判断变成最终决策。缺少同作者普通作品基线时只能标“高互动候选”，不能确认相对爆款；索引中的无标签数字不猜赞/藏/转含义。不以“查看AI文稿”按钮判断作品主题是否AI，该按钮仅表示平台提供文稿功能。
