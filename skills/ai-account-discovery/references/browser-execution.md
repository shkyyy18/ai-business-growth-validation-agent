# 浏览器执行、恢复与验收

按本轮真实工具schema调用。下列名称是能力示例，不是要求搭建新的浏览器服务。

## 最小自主闭环

1. 读取最新STATE及指定账号断点，记录原任务页URL、筛选条件与列表锚点。
2. snapshot确定页面；连接欢迎页只算连接成功。已有授权时用navigate进入用户任务页，不再重复安装/配置。
3. 指定账号优先使用关注列表内搜索，核对精确昵称与相似昵称。搜索后的计数是过滤结果，不是完整关注数。批量研究不要用“AI”关键词筛掉无AI昵称的账号。
4. 自行点击精确账号行。关注页可能只打开作品弹层，需再点击作者主页；取得真实主页路径/抖音号，不把当前视频作者或推荐区作者认错。
5. 新页只选择本次点击明确创建的页；读取主页、普通作品卡片，再打开代表作品获取日期、实际说明及可用正文/摘要。简介“更多”点击返回成功后仍要检查是否真的展开。
6. 逐条存证，再返回。使用navigate_back或关闭本任务创建的新页；必要时原生navigate回已知列表URL并恢复过滤条件。快照确认弹层已退出、处于列表上下文。
7. 保存断点及验收结果后才声称闭环完成。登录、验证码、连接授权由用户处理，普通导航不交还用户。

## 有限恢复

| 观察到的失败 | 允许的下一步 | 停止条件 |
|---|---|---|
| 工具目录缺少click/navigate | 保存缺项；配置已有时只请求一次客户端重新进入 | 重新进入后仍缺项则记录新证据，不反复改配置或声称能点 |
| ref失效/target无匹配 | 重新snapshot取得当前ref；target接受ref时传原值，不将ref猜写成`[ref=...]` CSS | 刷新一次仍定位不了则记录阻塞 |
| 等待visible/enabled/stable超时 | snapshot核对；可选择已确认的任务标签页后重试一次 | 再次超时则用已取得的真实链接原生navigate，或保存并停 |
| 元素被播放层遮挡 | 重新确认页面上下文，使用可见且同义的入口；有真实链接时navigate | 不强制盲点、不反复点击被遮挡元素 |
| 点击返回成功但页面未变化 | snapshot验证，可短暂wait_for后再读一次 | 没有目标身份/内容变化就不计业务成功 |
| 页面限流、验证码、权限拒绝 | 保存断点并交由用户处理必要授权 | 不换控制通道绕过 |
| 列表滚动无新增 | 验证焦点是否在列表，最多两次合理滚动/等待 | 保存“停滞、完整性未知”，不当作列表结束 |

选择任务标签页后点击成功只是本次观察到的恢复方法，不代表已证明后台节流是唯一原因。不能读取无关标签页来排障。

## 快照与证据保存

- 原始快照只存工具允许且已确认Git忽略的私有目录。MCP相对路径可能相对服务输出根，而非项目cwd；使用工具返回路径并在已知私有输出根核对真实文件，不改allowed roots，不扫描浏览器用户目录。
- snapshot子树可减少噪音；后续ref不在最近快照中时重新获取全页浅快照，而不是用旧ref重复失败。
- 页面作品总数、已加载卡片数、打开的详情数、读到的摘要数、完整观看数分别记录。自动播放进度和“刚刚看过”不是助手实际观看证据。
- 记录`access_mode=live_browser`以及每条`reading_level`。平台生成摘要须单独标记`platform_ai_summary`，不能记成作者原话或逐字稿。
- 每条证据保存观察时间、真实链接/ID、页面日期、来源快照、阅读边界。可计算快照SHA-256以支持回查，但哈希不能证明内容事实为真。
- 队列和身份结论与原始导入结果分开，更新检查点采用同目录临时文件后替换，写前保留既有证据。不要覆盖其他窗口的新结果。

## 验收必须逐项有实际结果

`导航 → 定位目标 → 点击账号 → 打开并确认主页身份 → 读取作品 → 返回列表 → 文件落盘`

每项记录pass/fail/not_tested及工具观察。返回成功需要新快照；保存成功需要文件确实存在且可解析。只有真实点击成功才能通过“点击”项；navigate成功不能替代它。单样本通过不是全量去重、批量稳定或无人值守验收。
