# 证据记录与交付口径

字段可用 Markdown 表或结构化文件保存；不要为填字段采集无关个人资料。未知值写未知，不置零。分批存储并保留索引，避免大段摘要失去原作依据。

## 账号卡

- 平台、账号稳定 ID（可取得时）、名称与链接；更名不视为新账号。
- 来源入口、发现时间、实际读取时间、观察窗口。
- 可见身份/定位、受众与产品线索；自述和顾问推断分列。
- 粉丝与互动快照，字段名称、单位与采集时间；缺图标或定义不清则暂不映射。
- 实际已读作品范围、常态表现参照及局限；临时分组与依据。
- 商业证据：产品挂牌、作者销售自述、可核对成交字段/时间段分别记录；没有成交记录就明确未知。

## 作品卡

- 作品 ID、平台、账号 ID、原链接、发布日期、采集日期。
- 材料层级：检索线索 / 可读原文字内容 / 平台 AI/智能文稿（与原音轨一致性未核验） / ASR 转写（注明来源与核对范围） / 原视频已实际查看（注明区间）/ 数据快照。可以并存，不能互相替代。
- 允许保留的素材位置、必要摘录或带时间段摘要；授权范围与读取缺口。
- 赞评转藏/播放等原始字段、采集时间、口径与缺失；禁止从未知图标猜指标。
- 选题、受众问题、观点、论据、结构、产品承接；区分直接观察与解释。
- 表现比较用的账号基线与窗口；没有可比数据就不赋予“爆款”标签。
- 研究价值理由、反例关系、待补材料、是否深拆及理由。

聚合页须分开标记主作品、推荐作品及各自作者；不能把推荐区文稿归到主作品，也不能直接把聚合页 URL 数字当作原作品 ID。平台 AI/智能文稿不自动等于逐字转写，未经原音轨核对，不据此还原精确开头、逐句顺序或时间点。

作品 ID 优先去重，规范链接辅助；文本近似只标候选重复。搬运/再发布可保留传播记录，但分析独立性时归到同一来源簇，不能虚增独立证据。

## 深拆卡

原作链接及已读范围 → 内容要解决的问题 → 开头/论证/结尾及具体定位 → 证据与表达的区别 → 可借鉴结构 → 迁移前提与风险 → 同类/反例对照 → 待验证假设。

只读转写时不分析未看到的镜头、节奏或表演。用户的客户案例必须来自授权材料；不以他人的亲身故事充当客户经历。结构借鉴不等于逐句替换或复制成稿。

## 进度计数

分别报告：已发现去重账号、已开展实质研究的账号、发现作品、取得原文/转写的作品、实际查看视频的作品、深拆作品、重复与失败项。各组有交集，不加总为“已读总数”。定义本批“有效读取”包含何种材料及是否完整。

历史“100 个账号、200 条内容”是用户回忆的人工筛选规模；其总阅读/最终入库/深拆口径未细分，不为比较 AI 效率自行补定义。

## 行业研究报告

1. 行业/渠道/时期/任务范围及实际来源能力。
2. 真实发现的行业版图和覆盖表；不能以未知行业总量计算覆盖率。
3. 账号库、作品库、深拆卡与可回溯索引。
4. 每项核心观察：来源簇、比较条件、反例、置信局限和影响的业务判断。
5. 本批新增认识、假设变化、访问失败及下一批选择理由。
6. 实际成本、时间与人工反馈（已取得时）；未取得则记录缺口。

报告状态取实际情况：发现扫描 / 扩展研究 / 深拆中 / 局部暂收口 / 访问受限 / 预算暂停。交付了报告不等于研究完成。

## 后续验收要测什么

数量扩展是能力指标之一，不单独证明质量。用真实素材检验：链接与原文追溯是否成立、重复是否误计、账号基线是否错配、哪些遗漏改变结论、选中的拆解是否被用户接受，以及实际成本/人工修订量。先记录用户接受与拒绝的具体理由，再调整采样和候选规则。

用户评审时展示原材料与对照，不让其凭孤立稿件判断网感。没有端到端数据读取和人工判断记录，只能验收流程或材料格式，不能验收行业研究能力。


## 公开页面字段小测的回退规则

可见静态 JSON 可用于核对主作品 ID、作者稳定 ID 和有名称的指标；这不意味着执行页面脚本、登录、调用收费接口或绕过访问限制获得授权。主作品卡链接与详情 ID 不一致时停止归属，保留冲突。

上游返回数字0时，先分辨实际观测零值与前端占位/不公开字段；无法确认则同时保留 raw=0 与 normalized=unknown，不用作分母。两个不同日期的离散作品不算连续列表，作者总获赞也不是这两条作品的表现基线。

对外同步只保存必要元数据、来源指纹和自写摘要。原文稿摘录、无许可源码快照、媒体地址签名、身份字段和客户原始资料不随研究报告自动公开。原视频未读时，即使有平台AI文稿也不能生成精确镜头/时间码建议。
