# 视频获取与分镜拆解

1. 确认作品与允许分析范围；已有获准素材先检查文件，不重复下载或覆盖。
2. 检查文件哈希、尺寸、帧率、时长、完整解码与音轨。可使用环境中已获准的媒体工具；没有工具就记录缺口。
3. 查看覆盖全时段的接触表，复核转场/快切/关键字幕附近帧；需要动态判断时实际看片段，记录复核范围。
4. 分开记录物理剪切、合成变化和表演节拍。逐项写时间码、画面、景别、动作、文字摘要、声音依据、转场与叙事作用。
5. 输出时间码表、关键帧、观察/推断/创作建议与缺口；若交付播放器，实际测试加载、跳转、图片及音轨。

抽帧覆盖不是完整动态观看；ASR不是人工听校，不能据静帧命名未听到的 BGM。自动帧差只提供候选切点。默认摘要和必要短引文，不把可下载当作再分发权。
